# ASTANA DARYNY — 20 лет

Одностраничный сайт-приглашение.

## Файлы
- `index.html` — весь сайт
- `assets/logo.png` — логотип компании

## GitHub
1. Создайте новый репозиторий.
2. Загрузите `index.html` и папку `assets`.
3. Сделайте commit.

## Render
1. New → Static Site.
2. Подключите GitHub-репозиторий.
3. Build Command: оставить пустым.
4. Publish Directory: `.`
5. Deploy.

Важно: текущая RSVP-форма показывает сообщение об успешной отправке на странице, но пока не сохраняет ответы на сервере. Для реального сбора ответов нужно подключить Formspree, Google Sheets или свой backend.
